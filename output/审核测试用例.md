## 测试准备

### 1. 申请 DeepSeek API Key

测试前需要准备一个 DeepSeek API Key：

1. 打开 https://platform.deepseek.com/api_keys
2. 登录或注册 DeepSeek 账号
3. 点击「Create API Key」，生成一个 Key
4. 复制保存（格式示例：`sk-xxxxxxxxxxxxxxxx`）

### 2. 创建测试多维表格

1. 在飞书中创建一个新的多维表格
2. 至少包含以下字段：
   - `文本内容`（文本字段）— 输入待分析文本
   - `分析结果`（字段捷径）— 选择「AI 数据助手」

## 注意事项

1. **API Key 安全**：该插件使用用户自备 DeepSeek API Key 模式，数据调用通过 HTTPS 加密传输，不会存储于任何服务端
2. **网络环境**：需要能够访问 `api.deepseek.com`（已在代码中配置域名白名单）
3. **响应时间**：首次调用可能需要 3-8 秒（取决于 DeepSeek API 响应速度），请耐心等待
4. **限流处理**：如连续快速调用过多，DeepSeek API 可能返回 429 限流错误，稍后重试即可
